## Text

A sentence with **bold**, _italic_, and ~~struck~~ words. An internal link to [Custom Button](/docs/components/custom-button), and an external link to [Fumadocs](https://www.fumadocs.dev).

1. Write the component in `registry/`
2. Describe it in `registry.json`
3. Build `public/r`

- Preview imports the registry source
- Consumers install into `components/ui`

> The registry file is the source of truth. The UI folder is the installed copy.

| Piece | Role |
| --- | --- |
| `registry.json` | Catalog of items |
| `registry/custom-button` | Source that gets published |
| `public/r/custom-button.json` | File the CLI installs |
